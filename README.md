# CAPA Recalc (เวอร์ชันเว็บ)

เว็บเพจที่คำนวณไฟล์ CAPA แทน macro **CAPA_Recalc** ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกส่งขึ้นอินเทอร์เน็ต
และไม่ต้องติดตั้งโปรแกรมใด

## วิธีใช้

1. เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge (ดับเบิลคลิกได้เลย ทำงานได้แม้ไม่มีอินเทอร์เน็ต)
2. ลากไฟล์ CAPA (`.xlsm` / `.xlsx`) มาวาง เว็บจะอ่านไฟล์และคำนวณทันที
3. ดูผลในแท็บต่าง ๆ
   - **ชั่วโมงงานต่อกระบวนการ**: ST × coefficient × Plan ÷ 3,600 ต่อเดือน
   - **ดูชีต**: ทุกชีตของไฟล์พร้อมค่าที่คำนวณใหม่ คลิกเซลล์เพื่อดูสูตร ที่มา และค่าเดิม
   - **เซลล์ที่เปลี่ยน**: เซลล์ที่ค่าต่างจากไฟล์เดิม
   - **คำเตือน**: ปัญหาในชีต PART METHOD และสูตรที่เว็บคำนวณไม่ได้
4. กด **ดาวน์โหลด** เพื่อได้ไฟล์ใหม่ (ชื่อเดิมต่อท้าย `_web`) ที่มีค่าที่คำนวณแล้ว
   รูปแบบเซลล์ ชีตอื่น และ macro ในไฟล์ยังอยู่ครบ

ตอนเปิดหน้าเว็บจะแสดง**ไฟล์ตัวอย่าง** (ข้อมูลสมมติ) ให้เห็นก่อนว่าผลออกมาอย่างไร

### ไฟล์ที่ใช้ได้

ไฟล์ CAPA ที่รัน `CAPA_Setup` (macro v13) แล้ว คือมีชีต `ST_SUM` และชีตซ่อน `CAPA_RULES`
ทั้งแบบที่สูตรอยู่ใน CAPA_RULES (ปกติ) และแบบหลัง `CAPA_EditFormulas` (สูตรอยู่ในเซลล์)
ไฟล์ที่ยังไม่เคยรัน CAPA_Setup ให้รันใน Excel ก่อนหนึ่งครั้ง

## ความเร็ว

วัดกับไฟล์ขนาดจริง: 42,000 รายการในชีต 1-2 (ค่า 792 คอลัมน์ต่อแถว ประมาณ 35 ล้านเซลล์), 400 เครื่องในชีต 1-3,
ไฟล์ 451 MB, Chrome บนเครื่องเดียวกัน

| ขั้นตอน | เวลา |
|---|---|
| เปิดไฟล์ + คำนวณทั้งหมด | 13 วินาที (อ่านไฟล์ 10.4 วินาที, คำนวณ 2.3 วินาที) |
| ดาวน์โหลด (ค่าเริ่มต้น) | 13 วินาที, ไฟล์ 16 MB |
| ดาวน์โหลดพร้อมค่ารายชิ้นงานของชีต 1-2 | 45 วินาที, ไฟล์ 171 MB |

เร็วขึ้นเพราะ
- คำนวณในหน่วยความจำด้วย JavaScript แทนการวนลูป Variant ใน VBA
- ไม่ต้องอ่านและเขียนเซลล์ผ่าน Excel ทีละช่วง
- ค่ารายชิ้นงาน 34 ล้านเซลล์ของชีต 1-2 (CH:AGS) ไม่ต้องเก็บ เว็บคำนวณเมื่อมีการอ่านค่านั้น

### ค่ารายชิ้นงานของชีต 1-2

ค่า ST × coefficient × Plan ของทุกรายการ ทุกกระบวนการ ทุกเดือน (CH:AGS) ไม่มีสูตรใดใช้
ยกเว้นคอลัมน์ Plan ที่ AGU:AHF ใช้ ดังนั้นโดยค่าเริ่มต้นไฟล์ที่ดาวน์โหลดจะเก็บเฉพาะคอลัมน์ Plan
ทำให้ไฟล์เล็กลงประมาณ 10 เท่าและเปิดใน Excel ได้เร็วขึ้น ผลของชีตอื่นทุกชีตเหมือนกัน
ถ้าต้องการค่าเหล่านี้ในไฟล์ด้วย ให้เลือก "เขียนค่ารายชิ้นงานของชีต 1-2 (CH:AGS) ลงไฟล์ด้วย" ก่อนดาวน์โหลด
(เซลล์เหล่านี้ใช้รูปแบบเซลล์ของแถวแรก คือแถว 7 ของแต่ละคอลัมน์)

## คำนวณเหมือน macro อย่างไร

โค้ดใน `src/core` แปลงมาจาก macro ทีละฟังก์ชัน

| macro (VBA) | JavaScript |
|---|---|
| `modCapaCalc`: BuildTotals, BuildQtyTotals, PART METHOD (FMCNC1 / FMCNC2 / HAND, Cnc2Shots), WriteMethodMarks, ChannelNote, CE_CheckStructure | `src/core/capa.js` |
| `modCapaEngine`: compiler สูตร R1C1, IF / IFERROR แบบ jump, peephole, SUMIF(S) / COUNTIF(S) พร้อม index และ cache, VLOOKUP, กฎ criteria ของ Excel | `src/core/engine.js` |

- ลำดับการบวกของผลรวม ST_SUM เหมือน macro ทุกขั้น ผลจึงตรงกันถึงหลักสุดท้าย
- ทดสอบด้วยไฟล์ที่มีรูปแบบเหมือนไฟล์ CAPA จริง
  - ทุกเซลล์สูตร (26,000 เซลล์) ตรงกับค่าที่ LibreOffice คำนวณ
  - ST_SUM และชีต 1-2 ตรงกับการคำนวณแบบอิสระด้วย Python
  - ไฟล์ที่แก้ข้อมูลแล้ว (Plan, coefficient, PART METHOD) คำนวณออกมาตรงกับค่าที่ควรได้ทั้ง 87,000 เซลล์
- ไฟล์ที่เพิ่งกด Recalc CAPA ใน Excel และยังไม่ได้แก้ข้อมูล แท็บ "เซลล์ที่เปลี่ยน" ควรเป็น 0
  ถ้าไม่เป็น 0 จะเห็นได้ทันทีว่าเซลล์ใดต่างกัน

### สิ่งที่ต่างจาก macro

- **สูตรที่พิมพ์เพิ่มหลังแปลงไฟล์**: macro ปล่อยให้ Excel คำนวณ เว็บคำนวณให้เองถ้าใช้ฟังก์ชันที่รองรับ
  ถ้าคำนวณไม่ได้จะใช้ค่าเดิมในไฟล์และแสดงในแท็บคำเตือน
- **ฟังก์ชันที่รองรับ**: IF IFERROR SUM COUNT SUMIF SUMIFS COUNTIF COUNTIFS VLOOKUP (แบบตรงค่า) INT MID NA TRUE FALSE
  และเครื่องหมาย `+ - * / ^ & % = <> < > <= >=` เท่ากับ macro
- **VLOOKUP แบบค่าประมาณ (TRUE)** หยุดพร้อมข้อความ เหมือน macro
- **ข้อความที่เป็นวันที่** (เช่น "1-2") ไม่ถูกอ่านเป็นตัวเลข ส่วน macro ถาม Excel
  ข้อความตัวเลขแบบอื่น (" 5", "$5", "1,000", "(5)", "5%") อ่านเหมือน Excel
- **Filter** ไม่ต้องปิด เพราะเว็บไม่ได้เขียนผ่าน Excel

## เบราว์เซอร์

Chrome / Edge 103 ขึ้นไป, Firefox 113 ขึ้นไป, Safari 16.4 ขึ้นไป (ใช้ DecompressionStream ของเบราว์เซอร์)
ไฟล์ใหญ่ควรใช้เครื่องที่มีหน่วยความจำ 4 GB ขึ้นไป (ไฟล์ขนาดจริงใช้ประมาณ 1 GB ระหว่างทำงาน)

## สำหรับผู้พัฒนา

```
index.html            หน้าเว็บที่ build แล้ว (ไฟล์เดียว) อย่าแก้ไฟล์นี้โดยตรง
build.mjs             node build.mjs  ->  index.html
src/core/             ส่วนคำนวณ (ทำงานใน Web Worker)
  util.js             ค่าแบบ Excel, การแปลงข้อความ/ตัวเลข, การเปรียบเทียบ
  model.js            workbook / sheet ในหน่วยความจำ
  zip.js              อ่าน/เขียนไฟล์ zip แบบ stream
  xlsxread.js         อ่าน .xlsx/.xlsm (อ่านชีตเป็น stream ข้ามค่า CH:AGS ของชีต 1-2)
  formula.js          แปลงสูตร A1 <-> R1C1
  engine.js           port ของ modCapaEngine
  capa.js             port ของ modCapaCalc (CAPA_Recalc)
  xlsxwrite.js        เขียนไฟล์กลับ เฉพาะเซลล์ที่เปลี่ยน ส่วนอื่นคัดลอกทั้งไฟล์
  api.js              คำสั่งที่หน้าเว็บเรียก
src/ui/               หน้าเว็บ (page.html, style.css, app.js) และไฟล์ตัวอย่าง sample.xlsx
test/make_fixtures.py สร้างไฟล์ทดสอบ (ต้องมี openpyxl และ LibreOffice Calc)
test/run-tests.js     node test/run-tests.js
test/e2e.js           ทดสอบหน้าเว็บใน Chromium (Playwright)
tools/make-big.js     สร้างไฟล์ขนาดจริงสำหรับวัดเวลา
tools/perf.js         วัดเวลาอ่าน / คำนวณ / เขียน
```

แก้โค้ดใน `src/` แล้วรัน `node build.mjs` และ `node test/run-tests.js`
ไฟล์ทดสอบใน `test/fixtures` สร้างใหม่ได้ด้วย `python3 test/make_fixtures.py`
ซึ่งจะสร้าง `src/ui/sample.xlsx` ใหม่ด้วย
